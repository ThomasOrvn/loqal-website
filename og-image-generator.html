Instructions pour générer l'image OG

  1. Ouvrez ce fichier dans un navigateur
  2. Faites un clic droit sur le rectangle vert (1200×630px) ci-dessus
  3. Prenez une capture d'écran de cette zone exacte :
    • macOS : Cmd+Shift+4, puis sélectionnez la zone
    • Windows : Outil Capture d'écran
    • Ou utilisez un outil comme : Screenshot.guru, Screely
  4. Enregistrez l'image sous le nom og-image.jpg
  5. Placez-la dans le dossier public/
  6. Optionnel : optimisez l'image avec TinyPNG

💡 L'image OG (Open Graph) s'affiche quand vous partagez le site sur les réseaux sociaux (Facebook, Twitter, LinkedIn, etc.). Dimensions recommandées : 1200×630px.
